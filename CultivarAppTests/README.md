# CultivarAppTests

The repo includes a checked-in Xcode project at `Cultivar.xcodeproj`.

## Run In Xcode
1. Open `Cultivar.xcodeproj`.
2. Select the `Cultivar` scheme.
3. Run `Product > Test`.
